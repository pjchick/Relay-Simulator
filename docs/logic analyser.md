I want to create a new tool called logic analyser.

##Phase 1##

The logic analyser should be opened from the menu as a modeless window.

When the analyser is opened a classic logic analyser interface will be presented in a separate window.

The Logic analyser can have as many channels as I want. The user should be able to add and remove channels.

A channel will be connected to a LINK via the 'LINK NAME' property.

Logic analyser configurations will be stored in the .rsim file. An .rsim file can hold multiple logic analyser configurations.

The User should be able to add remove and edit these configurations.

The logic analyser window should have Start / Stop and Clear buttons.

##Phase 2##

Trace screens should be able to be saved as images.

Users should be able to zoom into the traces.
